STUDENT PROJECT
Основная информация о проекте
================================

Название проекта: Student Project
Назначение: учебный проект для практической работы №2 по организации репозитория в GitHub.

О ПРОЕКТЕ
---------
Student Project создан для демонстрации базовых принципов работы с системой контроля
версий Git и сервисом GitHub.

Основная задача проекта — организовать хранение файлов в удалённом репозитории,
научиться фиксировать изменения с помощью commit и работать с несколькими ветвями
проекта.

СОСТАВ ПРОЕКТА
--------------
1. Base.txt
   Основная информация о проекте и его назначении.

2. calculator.py
   Небольшая учебная программа-калькулятор, демонстрирующая работу с исходным кодом.

3. report.docx
   Краткий отчёт о структуре и назначении учебного проекта.

4. documentation.pdf
   Документация с описанием файлов проекта и принципов его организации.

5. diagram.jpg
   Графическая схема структуры проекта и его связи с репозиторием GitHub.

ОРГАНИЗАЦИЯ В GITHUB
--------------------
Основная ветвь проекта называется main.

Для демонстрации работы с ветвями проекта предусмотрены дополнительные ветви:
development и feature.

Изменения в репозитории фиксируются отдельными commit. Это позволяет сохранять
историю изменений и отслеживать развитие проекта.

РЕЗУЛЬТАТ
---------
В результате создан учебный репозиторий, содержащий файлы разных форматов.
Проект предназначен для практического освоения базовых возможностей Git и GitHub,
включая загрузку файлов, создание ветвей и фиксацию изменений.

Версия проекта: 1.0
Тип проекта: учебный
Изменение выполнено в ветке feature.
